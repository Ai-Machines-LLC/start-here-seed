ERROR_CODES (v0.1.0) - one exit-code table for every seed script. Owner: the Builder role; changes go through review (H19).
Why: a missing, renamed or moved file or folder must fail loudly with a clear code, never guess or carry on. Every script
checks the paths it needs at startup, before it reads or writes anything, and stops at the first missing one.
Rule for messages: one line on standard error, "ERROR <code> <NAME> | <path or key> | <what to do>". The path printed is the
one the script was given (never a secret value). Scripts hold no exact paths: every path comes from the command line or from
a config file the command line names, and may be relative to a configured root.

code | NAME                  | meaning
0    | OK                    | ran and found nothing wrong
1    | FINDINGS              | ran; the check found problems (listed above the summary line)
2    | USAGE                 | bad or missing command-line option or value (also argparse's own errors)
3    | TOGGLE_OFF            | toggle.py --check: the named leader or cycle is OFF
10   | CONFIG_MISSING        | a config file named on the command line does not exist
11   | CONFIG_KEY_MISSING    | a required key is in neither the command line nor the config file
12   | ROOT_MISSING          | the configured root or seed folder does not exist
20   | FILE_MISSING          | a required input file does not exist (missing, renamed or moved)
21   | FOLDER_MISSING        | a required input folder does not exist (missing, renamed or moved)
22   | OUTPUT_PARENT_MISSING | the folder an output goes into does not exist (scripts never create it, H24)
23   | TOOL_MISSING          | a program or library the script needs is not installed (git, bash, Pillow)
24   | SCRIPT_MISSING        | a sibling seed script this script runs is not in the scripts folder
30   | BAD_FORMAT            | a file exists but its header, columns or structure are not what the script reads
31   | BAD_VALUE             | a value inside a file cannot be used (not a number, not a date)
40   | SCAN_HITS             | library_intake_scan.py: the library holds paths, personal data or secret patterns
50   | WARN_ASSUMED_ON       | toggle.py: status file missing, treated as ON so work is not blocked (warning; the Designer
     |                       | 2026-11-22 8:54 PM ET: "just fix it", option B). Callers decide whether to stop.

PROBES - check_scripts.py --probes runs each line in an empty temporary folder and expects the exit code.
{MISSING} is a path that does not exist; {EMPTY} is an empty folder; {SCRIPTS} is the scripts folder under test.
