## How to use a KUKA manual on a job
5. Match the manual to the controller's system software version (KSS) before you follow it.
6. Note the manual's title, version and the section you used in the project's own docs, not here.
7. Machine-specific settings found while reading (addresses, I/O maps, program numbers) go in the project folder only.
